# Source Marker v1.0.0

面向 Adobe Premiere Pro **源监视器（Source Monitor）** 的剪辑与导出增强面板。
2026-10-06 发布 ｜ 已在 Premiere Pro 24.0.0 / Windows 上完整实测通过。

---

## 下载哪个

| 文件 | 适合谁 | 里面有什么 |
|---|---|---|
| **`source-marker-1.0.0.zip`** | **绝大多数人** | 新手版面板 + 安装脚本 + [`快速上手.md`](../快速上手.md) |
| `source-marker-1.0.0-full.zip` | 需要排错或自定义的人 | 完整版面板（含自检、导出策略选择、文件名模板）+ 技术 README |

两个版本**扩展 ID 相同**，同一时间只能装一个，互相覆盖。

---

## 安装（3 步）

1. 解压后**双击 `install.cmd`**，弹出提示点「是」（需要管理员权限写入 Program Files）
2. **完全退出** Premiere Pro（任务管理器里确认没有残留进程），重新打开
3. 顶部菜单 **`窗口 > 扩展 > Source Marker`**

> 如果双击 `install.cmd` 一闪而过，说明出错了——改用命令行运行 `install.ps1 -DryRun` 可以看到它打算做什么而不实际改动。

---

## 能做什么

| 能力 | 说明 |
|---|---|
| **一键导出源监视器的入出点范围** | 划好入出点直接出片，省掉「做 subclip → 去项目面板 → 导出」的绕行 |
| **入出点精确编辑** | 键入时间码、按帧微调、跳到入点/出点、与时间线互拷、清除 |
| **跳到任意标记** | 点标记列表里的一条，源监视器播放头直接跳过去 |
| **插入 / 覆盖到时间线** | 指定视频轨和音频轨，轨道号与 Pr 界面一致（V1 = 第一条） |
| **导入标记文件** | CSV / TSV / JSON / SRT，一次导入整批标记 |

导出的目录和格式**只需设置一次**，之后自动记住。导出会直接交给 Adobe Media Encoder 并自动开始渲染。

---

## 环境要求

- **Premiere Pro CC 2019（13.0）或更高**（清单里声明的宿主范围是 `13.0 ~ 99.9`）
- **Adobe Media Encoder**（导出功能依赖它，必须安装）
- 一个 Media Encoder 输出预设（`.epr` 文件）；没有的话：AME → 菜单「预设」→「导出预设」
- Windows（安装脚本是 PowerShell；macOS 需手动把 `extension/` 放进 CEP 扩展目录）

## 实机验证结论（Pr 24.0.0）

五项能力全部在真机上跑通，不是"应该可以"：

| 能力 | 实测证据 |
|---|---|
| 导出入出点范围 | 请求跨度 50.040s → 产物 **50.069s**（误差 0.029s，不到一帧），文件 114.8MB → 46.0MB |
| 入出点编辑 | `setInPoint` 写回与请求一致 |
| 跳到标记 | `tc=00:02:05:16 \| now=125.640` 精确吻合 |
| 插入 / 覆盖 | 轨道对应正确 |
| 导入标记 | `added=2 \| failed=0`，命名规则符合预期 |

排查过程中被真机推翻的 5 个假设（`Time.timecode` 不存在、`setInPoint()` 返回 `null`、
`encodeProjectItem` 不认子剪辑裁剪、`deleteBin()` 返回 true 却不删任何东西、
`app.bringToFront()` 不存在）记录在完整版的 README 里，改代码前建议先读。

## 已知限制

1. **导出只能在「临时序列」策略下工作。** 实测 Pr 24.0 的 `encodeProjectItem` 无论传什么参数
   都会导出整条素材，所以新手版把策略固定为唯一可用的那条。
2. **导出会在工程里留下一个 `SM 00.00.00.00-…` 命名的临时序列**，AME 渲染期间必须存在
   （没有渲染完成回调，无法自动删）。渲染结束后点面板右下角「清理导出产生的临时序列」即可。
   清理**只删以 `SM ` 开头的序列，且跳过当前活动序列**。
3. **发布头的定位走 QE 通道**（Adobe 官方 API 确实不支持），用的是 Adobe 官方示例 PProPanel
   里的写法。QE 不受官方兼容性承诺保护，已做存在性探测与明确报错。
4. **标记的显示名取自文件里的「内容/备注」列**；标记文件里的 `name` 列**整列忽略**
   （播放器早先会在那一列写 `M01`/`M02` 占位编号，合并版已不再生成）。

## 配套：播放器端标记生成（mpv）

本面板是标记格式的**读取方**。写入方是同一仓库的 mpv 插件 `player-plugin/source-markers.lua`
（`Ctrl+m` 打标记 / `Alt+m` 写描述 / `Ctrl+e` 导出），格式规范见 `docs/marker-format.md`。

## 版本管理

- 完整版快照存档在 `backup/source-marker-full-20261006/`（含构建当时的全部诊断能力）

# 备份：完整版（含开发与诊断工具）

**快照日期**：2026-10-06
**对应状态**：全部功能已在 Premiere Pro 24.0.0 / Windows 上真机验证通过的那一刻。
扩展目录 6 个文件已与仓库逐个 MD5 比对一致后才归档。

---

## 这是什么

仓库根目录的 `extension/` 后来被改造成了**新手版**（删掉测试与开发性选项）。
本目录保留的是改造前的**完整版**，功能更全，但界面上有大量面向排错的按钮和术语。

版本号、扩展 ID、安装路径与新手版完全相同（`com.frisk.sourcemarker`），
所以**两个版本会互相覆盖**，同一时间只能装一个。

## 与新手版的差异

| 功能 | 新手版 | 本备份（完整版） |
|---|---|---|
| 自检（一键探测本机 Pr API 支持情况） | ✗ | ✓ |
| 探测 QE（诊断「跳到」是否可用） | ✗ | ✓ |
| 导出策略可选（序列 / 子剪辑 / 直接编码） | ✗ 固定为序列策略 | ✓ 三选一 |
| 文件名模板 `{clip}` `{in}` `{out}` `{date}` | ✗ 固定为「素材名_in入点」 | ✓ 可编辑 |
| 扩展名手动覆盖 | ✗ | ✓ |
| 界面文案 | 面向新手，无术语 | 含 API 名称与技术说明 |
| 状态日志 | 精简 | 完整 |

## 怎么安装

双击本目录下的 **`install.cmd`**（会覆盖新手版）。

## 怎么装回新手版

双击仓库根目录的 **`..\..\install.cmd`**（相对本目录）。

## 什么时候需要用到这个版本

- 面板出现异常行为，需要跑「自检」看本机 API 的实际支持情况
- 新手版的序列导出策略在你的 Pr 版本上不工作，想试另外两种策略
- 需要自定义输出文件名规则

## 已知的机制说明（避免重复踩坑）

完整版 README 里记录了 5 条被真机实测推翻的假设，包括：
`Time.timecode` 不存在、`setInPoint()` 返回 `null`、`encodeProjectItem` 不认子剪辑裁剪、
`deleteBin()` 返回 true 却不删任何东西、`app.bringToFront()` 不存在。
排错前建议先读一遍，能省很多时间。

## 三、第 9 条 A 半（Pr 风格可缩放时间轴）当前实现状态

主文件：`source-marker-united-1.2.0-alpha-r46\mpv-player\portable_config\scripts\source-markers.lua`
（缩放/交互引擎包在 `tl_init()` 里以绕开 Lua 5.1 单函数 200 个 local 上限；对外挂在 `TL.*` 表上。）

已实现并验证：

1. **静态版式**：宽 84% 窗口、6 行（两端时间码 / 刻度标签 / 标记盾形 / 刻度基线 / 概览条在块底部 / 播放头盾形）；盾形头型、当前帧蓝扁条、出入点蓝带 + 白括号。
2. **刻度阶梯**：≥1s 时钟档 1/2/5/10/15/30s（每大格恒 5 段）；<1s 帧档（fps 整数因子且 ≥2 帧，小格份数 5/4/3/2）；标签 `MM:SS` / `SS:FF`（帧档带 `f`）。
3. **播放头吸帧**：一帧 ≥6 px（蓝扁条出现）时播放头吸到帧头。
4. **缩放/平移**：滚轮/Ctrl/Shift 步长 `tl_zoom_steps='1.003,1.001,1.01'`；`Alt+=`/`Alt+-`/`Alt+0`（×2 / 复位）；锚点 `tl_zoom_anchor='snap'`（缩放后播放头回区间正中）；`Alt+滚轮` 平移。
5. **点刻度带**跳转（吸帧起点 + 同步重绘，实测重绘 6.0 ms）；**双击**回全域（全屏改绑 F11，`keybind MBTN_LEFT_DBL ignore`）。
6. **两端时间码**可点，弹出输入框，`parse_tc` 支持 Pr 式纯数字（`2200`→22s0f、`2245`@30→23s15f）与带分隔符格式。
7. **概览条三抓手**：点抓起 → 移动 → 再点放下；**ESC / 任意区域点击 / 空格回车方向键**都能中断（`sm_tl_grab_any`、`sm_tl_grab_keys`）；贴边钉住（`at_head`/`at_tail`）；拖圆两阶段（`|p0-0.5|≤0.02` 对称，否则缩=远端动、放=被抓端动）；手感模式 `tl_grab_feel='pr'|'mouse'`；最小跨度 `tl_min_px=40`（30s 片 ⇒ 2.420 s）。
8. **滚轮分区**：刻度/轨道区滚轮 = 播放头 ±1 帧（向上=后退一帧），概览条区滚轮 = 缩放；用 `mouse-pos` 判区（不用 input section 分派 wheel）。
9. **滚动跟随**：`tl_follow_playhead()`，播放头越出区间即居中；播放跟随模式 `tl_play_follow='off|pr|page|center'`（默认 `pr` = 播放中不动、暂停追平）。
10. **跨重启记住**：`ui.json` 的 `tl_file/tl_t0/tl_t1`（按 basename 记）。
11. **概览条非线性映射**（与 Pr 拟合）：`tl_ov_map='bar'`、`tl_ov_pow=1.30`、`tl_ov_k=1.19`、`TL.bar_k(u)=1+(tl_ov_k-1)*(u/0.5)^0.68`。残差：位置 5–10 px、亮段宽偏宽 ≤17 px，暂不追。
12. **刷新率**：`time-pos` 观察者节流 0.05 s（20 Hz）。

## 六、无头探针约定（本轮新立，务必遵守）

```powershell
# 跑前必须先写 ui.json，否则 style 不是 prbar、时间轴不渲染、日志只有启动几行
Set-Content <包>\mpv-player\portable_config\source-markers-ui.json -Value '{"help":false,"hint_shown":true,"panel":false,"show_list":false,"mode":false,"style":"prbar","bar":true}' -Encoding ASCII

# 不需要截图一律 --vo=null --ao=null，探针末尾必须 mp.commandv('quit')
& <包>\mpv-player\mpv.com --vo=null --ao=null --pause=yes --keep-open=no "--script=<探针>.lua" "--log-file=<日志>" --msg-level=all=v <素材>
```

- 不用 `mpv.exe`（GUI 子系统、无输出、无退出码）。
- 取证钩子：`script-message state` / `dump` / `keys` / `prbar` / `tl <t0> <t1>` / `tl-goto <时间码>` / `tl-hit <x> <y>` / `tl-wheel-at <x> <y> <±1>` / `tl-follow <mode> [t] [1]` / **`tl-grab <left|right|mid>` + `tl-drag-n <0..1>`**（归一化坐标，不依赖窗口尺寸）。
- 测延迟不要看 `time-pos` 属性（瞬间就更新），要看日志里的 `first video frame after restart shown`。

## 七、本轮踩过的坑（别再踩）

1. **`|p0-0.5|` 必须留容差**：p0 恰为 0.5 会落进"钉住右端"分支，表现为"放大只往左长"（EPS=0.02 已修）。
2. **概览条"中心+宽度"两段式映射必须钉边界端点**，否则贴片头时"本该不动的左端"会漂出去又回来（u≈0.7 时约 10 px）。
3. **`script-opts\source-markers.conf` 是运行时状态**（mpv 每次运行重写），已 `.gitignore` 并从仓库 `git rm --cached` 剔除；别再提交它。
4. **探针不 quit 会留窗口**，用户会要求手动关（已犯过一次）。
5. **`scripts\` 目录只许放 `.lua`**：误放一个 json 进去，mpv 每次启动刷 `Can't load unknown script`。
6. **ASS 颜色是 BGR**：蓝色是 `&HFFA64D&`。
7. 改包名（升 r）时必须连 `.py/.cmd/.bat/.xml` 一起改，否则许可取证脚本会指着旧路径报退出码 2。

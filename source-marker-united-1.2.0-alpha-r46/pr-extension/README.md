# Pr 面板：装哪个？

这里有两个版本，**功能都在，装一个就行**。两个版本**扩展 ID 相同**
（`com.frisk.sourcemarker`），同一时间只能装一个，后装的会覆盖先装的。

| | 新手版 | 完整版 |
|---|---|---|
| 目录 | `新手版\` | `完整版\` |
| 面向 | 日常剪辑使用 | 排错、自定义 |
| 界面 | 精简过的新手界面 | 原始界面，功能区更全 |
| 自检按钮 | 无 | **有**（一次点击探测本机全部依赖 API） |
| 导出策略选择 | 无（固定为唯一可用策略） | 有 |
| 文件名模板 | 无 | 有 |
| 技术 README | 无 | 有（`完整版\README.md`，含被真机推翻的 API 假设） |
| 上手说明 | `新手版\快速上手.md` | `完整版\快速上手.md` |

## 安装

进对应目录，双击 **`install.cmd`** → 提示点「是」→ 完全退出 Premiere Pro 再重新打开 →
`窗口 > 扩展 > Source Marker`。

## 换版本

直接装另一个即可（会覆盖）。装完如果行为没变，多半是 Pr 没有完全退出 ——
确认任务管理器里没有 `Adobe Premiere Pro.exe` 残留再重开。

## 其它

- 两个版本的**宿主脚本（引擎）逐字节相同**，差别只在界面层。所以"换版本"不会引入新的真机风险。
- 卸载：在对应目录里运行 `install.ps1 -Uninstall`。
- 两个版本共用扩展 ID，所以**不会**出现"两个面板同时存在"的情况。

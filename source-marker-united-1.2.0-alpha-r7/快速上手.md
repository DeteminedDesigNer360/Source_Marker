# Source Marker 合并版 · 快速上手

这个包里有**两块东西**，各自安装、互不依赖，只用一个也行：

| | 在哪 | 干什么 |
|---|---|---|
| **mpv 播放器** | `mpv-player\` | 边看片边打标记（时间戳 + 颜色 + 描述），导出成标记文件 |
| **Pr 面板** | `pr-extension\` | 在 Premiere 里把标记文件导入成标记；另外还能一键导出源监视器的入出点范围 |

两个都用，就是「看片时打标记 → Pr 里看到标记」一条龙。下面按这个顺序讲。

---

## 一、先装 Pr 面板（装一次就好）

1. 进 **`pr-extension\新手版\`**，双击 **`install.cmd`**
   - 只想用日常功能就装**新手版**；需要自检、导出策略选择、文件名模板就装
     **`pr-extension\完整版\`**。两个版本**扩展 ID 相同，同一时间只能装一个**，互相覆盖。
2. 弹出「是否允许更改」点 **是**（要写入 Program Files，需要管理员权限）
3. **完全退出** Premiere Pro（任务管理器里确认没有 `Adobe Premiere Pro.exe` 残留），再重新打开
4. 顶部菜单 **`窗口 > 扩展 > Source Marker`**

> 如果双击 `install.cmd` 一闪而过，说明出错了 —— 改用命令行运行 `install.ps1 -DryRun`，
> 它会说明打算做什么而不实际改动。
> 如果菜单里没有这个面板，先确认 Pr 是真的全部退出了。

---

## 二、用播放器打标记

1. **解压**本包到任意目录（桌面、文档、D 盘都行；**不要**放进 `C:\Program Files`，
   那里可能没有写权限）
2. 把视频**拖到 `mpv-player\mpv.exe` 上**（或拖到 `mpv-player\打开视频.cmd` 上）
3. 按 **`F2`** 打开按钮面板 —— 所有功能都能用鼠标点；不熟悉的话先按 **`F1`** 看快捷键
4. 打到满意的标记后按 **`Ctrl+e`** 导出，屏幕左上角会显示导出路径

常用键：`Ctrl+m` 打标记 ｜ `Alt+m` 打标记并写描述 ｜ `Ctrl+1`…`Ctrl+8` 选颜色 ｜
`Alt+n` / `Alt+p` 跳上下一个标记（帧精确）｜ `Ctrl+DEL` 删除最近标记 ｜ `Ctrl+i` 导入标记文件。

---

## 三、把标记带回 Pr

1. Premiere → `窗口 > 扩展 > Source Marker`
2. 在**源监视器**里打开**同一个素材**（标记是挂在素材上的，换素材看不到）
3. 点 **「选择文件…」**，选刚导出的那个 `.csv`（CSV / TSV / JSON / SRT 都认）
4. 想覆盖这个素材上原有的标记，就勾上「导入前先清空已有标记」
5. 点 **「导入」**，下方列表会出现所有标记，**点任意一条就能把播放头跳过去**

---

## 四、另外三件顺手的事（Pr 面板）

**导出源监视器里划好的一段**

1. 源监视器里用 Pr 自带的 `I` / `O` 划出入点出点
2. **第一次使用**填两个位置，各点一次「选择…」：
   - **保存到** → 选一个文件夹
   - **输出格式** → 选一个 Media Encoder 预设（`.epr` 文件）

   这两个**只需选一次，以后自动记住**，重开 Pr 也还在。
3. 看一眼「文件名」那一行，点 **「导出这一段」**

导出交给 Adobe Media Encoder。勾了「导出后自动开始渲染」的话它会自己跑，别关 AME。

**把这一段放到时间线**

先在时间线面板把播放头放到想插入的位置 → 面板上选「插入」或「覆盖」→
填轨道号（**V1 就是第一条视频轨**）→ 点 **「放到时间线」**。

**入点 / 出点那一栏**

可以直接键入时间码（`00:00:10:00`）后点「应用」，也能按帧微调、跳到入点/出点、
与时间线互拷入出点、清除。

## 五、常见问题

**导出后 Pr 工程里多了一个叫 `SM 00.00.10.00-…` 的序列？**
那是导出用的临时序列，必须存在到 AME 渲染结束。渲染完成后点面板右下角的
**「清理导出产生的临时序列」**即可一次清掉（只删 `SM ` 开头的，不会动别的序列）。

**点了「导出这一段」没反应？**
看面板底部「状态」那块的文字，它会说明卡在哪一步（例如预设文件找不到、输出文件夹不可写）。

**手上没有 `.epr` 预设文件？**
打开 Adobe Media Encoder → 菜单「预设」→「导出预设」，随便存一个到好找的位置。

**播放器导出的文件在哪？**
屏幕左上角会显示完整路径。默认与视频同目录，文件名形如
`你的视频名_markers_20261006-1830.csv`（同时会写一份同名 `.json`，信息更全）。

**视频旁边那个 `.marks.json` 是什么？**
播放器自动保存的标记文件 —— 关掉再打开同一个视频，标记会自动回来。
它**默认是隐藏文件**，以防误删误改。

**描述和名字是怎么回事？**
Premiere 那边把「描述」当作标记的显示名，所以播放器**只让你填描述**。
标记文件里的 `name` 列整列忽略（播放器写空，Pr 也不用它）。

**播放不流畅 / 黑屏？**
在 `mpv-player\portable_config\mpv.conf` 里加一行 `hwdec=auto` 试试；
老显卡可以改成 `hwdec=no`。

**想改键位、改面板位置？**
见 `mpv-player\README.md` 的「可调项」一节，或按 `F1` 里的提示。

**想反馈 Pr 面板的问题？**
点面板里的「复制状态信息」，把复制到的内容发出来即可。

**不要了 / 怎么卸载？**
- 播放器：整个文件夹删掉就完事。
- Pr 面板：`install.ps1 -Uninstall`（两个安装位置都会清理）。


## 标记模式（1.2.0 起）

`F10` 开关。开启后**右下角有个小标**，此时这几个键向 Pr 的源监视器看齐：

| 键 | 动作 |
|---|---|
| `M` | 在当前播放头打标记 |
| `Shift+M` | 跳到下一个标记 |
| `Ctrl+Shift+M` | 跳到上一个标记 |
| `Del` | 删除播放头处的标记 |

不开模式时这些键就是 mpv 原本的功能（`m` = 静音）。**开关状态会被记住**，下次打开还是上次的样子。

> 若你自己写过 `input.conf` 并占用了上面任意一个键，**你的绑定优先**（mpv 的规则），模式的对应键会失效 ——
> 那就删掉那几行，或改用 `Ctrl+m` / `Alt+m` 等既有快捷键（它们一直都在）。

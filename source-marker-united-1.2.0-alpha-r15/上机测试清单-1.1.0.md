## 10. 以下**不是**缺陷，是已确认的能力边界

- [x] 点面板标记后，Pr 的**活动监视器**仍留在原处（按空格播的是它最后被点的那个监视器）
  —— **实测更准的说法（用户修正）**：只要「源」监视器不是在 Pr 的**蓝色选框**下，
  按空格播放的总是序列 —— 即"播哪个"由 Pr 里最后被点中的那个面板决定。
  面板改不了它（自检实测 `activate/setActive/open/bringToFront` 全是 `undefined`），替代方案是「播放源」按钮。
  替代方案：面板上的「播放源」按钮，或在 Pr 里手点一下源监视器。
- [x] CEP 面板内**所有**文本输入框的中文候选窗位置都不可靠 —— 这是 CEP/CEF 通病。
  所以改标记正文走的是 **Pr 原生输入框**（那里正常）。
- [x] 按「暂停源」后画面停住；Pr 传送按钮的图标**随版本而异**（**r21 实测为三角形**）——

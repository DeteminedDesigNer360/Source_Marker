## 步骤 12（r48-1）：面板位置自由化（2026-10-24）

- [ ] 1. 位置记忆：打开面板 → 关掉 mpv → 再打开同一个文件，面板位置与上次一致（`source-markers-ui.json` 里能看到 `panel_pos`）。
- [ ] 2. 夹紧：把窗口缩到很小（例如 800×500）再开面板，面板不会跑到窗口外（从左上角起画，右侧允许溢出）。
- [ ] 3. 按钮紧凑：每个按钮的宽度应该**正好包住文字 + 一点内边距**，文字右边不再有大片空白（r47 每个按钮多留了约 2.6 个字的空白）。
- [ ] 3b. 文字居中：任取几个按钮（含「切换 OSD 样式」这种中英混排、含「（另存为迭代）」这种带全角括号的），文字左右两边的空白应该**看起来一样宽**，没有一边贴边。
- [ ] 4. 常用窗口（1165×651 / 1280×720 / 1600×900）下**字号与 r47 一样、不缩**，且 24 个按钮全部在窗口内（r47 里最右的「切换 OSD 样式」「标记模式」会被窗口裁掉）。
- [ ] 4b. 极小窗口（800×500 左右）面板会自动缩字号（最小 12 px）保证放得下；再小就允许右侧溢出。
- [ ] 5. 面板最小化（左下角 ＋ 方块）行为不变；关面板再开，位置不清零。
## 步骤 13（r48-2）：面板抓手 ⠿ 与拖动状态机（2026-10-24）

> 这一轮**还没有鼠标跟随**：抓起来之后面板不会跟着鼠标走（R48-3 才做）。现在验的是状态机、互斥、视觉反馈。

- [ ] 1. 抓手在：面板标题行**最左边**有一个 ⠿ 小方块，标题文字（Source Markers）在它右边，两者不重叠。
- [ ] 2. 抓起：用鼠标点 ⠿ → 标题变成金色「移动中 · 点 ⠿ 放下 · ESC 取消」，⠿ 自己变成蓝底白字，左上角还会弹一行同样的提示。
- [ ] 3. 放下：再点一次 ⠿ → 一切恢复原样（标题变回「Source Markers」、⠿ 变回灰底）。
- [ ] 4. 键盘等价：按 **Alt+F3** 抓起、再按一次放下 —— 效果与点 ⠿ 完全相同；面板被 F2 隐藏、或被 − 最小化时，Alt+F3 也能抓起/放下。
- [ ] 5. 取消：抓起后按 **ESC** → 面板回到**抓起前**的位置（本轮面板还不会动，所以这一点要等 R48-3 才真正看得出）。
- [ ] 6. **防误触**：抓起状态下，其它按钮的文字都变灰、鼠标点上去毫无反应（`打标记` 点了**不应该**打出标记）。
- [ ] 7. 键盘不受影响：抓起状态下按 Ctrl+M 照样能打标记、按 F2 照样能切面板、按 F3 照样能换样式。
- [ ] 8. 退出拖动后再点普通按钮，全都恢复正常（包括颜色 0~7 的色块）。
- [ ] 9. 连续抓/放 5 次以上不出错、文字不变形、位置不漂。
- [ ] 10. 关面板（✕ 或 F2）再打开，抓手还在、状态已复位（不会一打开就是「移动中」）。
## 步骤 14（r48-3）：面板跟着鼠标走 + 视觉细节（2026-10-24）

- [ ] 1. 跟随：点 ⠿ 抓起后**移动鼠标**，面板整体跟着走，⠿ 一直吸在鼠标下（不应该越拖越偏、也不应该只在水平方向跟）。
- [ ] 2. 触边：把面板往窗口右下角拖，面板整体停在窗口内（不外溢）；鼠标继续往外走面板不动；鼠标移回来面板立刻继续跟。
- [ ] 3. 四个方向都试一遍（左上 / 右上 / 左下 / 右下），面板都不能有一半跑到窗口外。
- [ ] 4. 放下（再点 ⠿ 或 Alt+F3）后位置就停在那儿；按 ESC 则回到抓起前的位置。
- [ ] 5. 跟随时不卡顿：快速画圈移动鼠标，面板应该连续跟手（允许轻微滞后，但不能一跳一跳）。
- [ ] 6. **色块去饱和**：抓起状态下，颜色 0~7 的八个色块应该整体变得灰一些（绿→灰绿、红→暗红…），文字变灰；但**仍然认得出**是哪个颜色（不是全变黑白色块）。放开后恢复鲜艳。
- [ ] 7. **抓手激活 = 亮蓝**：点 ⠿ 抓起后，最左那块 ⠿ 底色变成**亮蓝色**（与标题同色），标题同时变成「移动中 · 点 ⠿ 放下 · ESC 取消」；放下后恢复灰底。
- [ ] 8. **普通按钮悬停仍是土黄**：鼠标移到「打标记」等按钮上，底色是原来那层土黄（*不应该*变成亮蓝）；悬停颜色块（0~7）时也保持它自己的颜色。
- [ ] 9. 拖动中悬停到别的按钮上，不应该出现任何高亮（它们此时是禁用的，保持灰字淡底）。
- [ ] 10. **移出窗口自动放下**：抓起面板后把鼠标拖出 mpv 窗口（停在窗口外不动），约半秒后拖动自动结束（面板留在最后位置、不再跟手）；鼠标移回窗口内面板不会瞬移。
- [ ] 11. 抓起后**原地不动**超过约 0.6 秒也会被自动放下（设计如此，位置保留，可立刻再抓起）；按 ESC 才是回原位。

## 步骤 15（r48-4）：面板位置记住 + 拖动互斥（2026-10-24）

- [ ] 1. 把面板拖到窗口里别的地方（比如右上附近），再点 ⠿ 放下；**完全关闭 mpv 重新打开同一个文件**，面板应该出现在你上次拖到的位置（不是回到左下 40 那个默认点）。
- [ ] 2. 重启后位置若超出可见区（比如换了更小的窗口 / 更低分辨率），面板会被自动拉回窗口内，四个角都不外溢。
- [ ] 3. **关面板不清位置**：按 F2 关掉面板，再按 F2 打开（不做拖动），面板还在刚才那个位置。
- [ ] 4. 按 F3 切到 Pr 风格控制栏（面板隐藏）后再按 Alt+F3：不进入拖动，顶部提示「面板没显示，按 F2 或点显示后再拖」。
- [ ] 5. 点面板标题行的 **−** 把面板折叠成最小条，再按 Alt+F3：不进入拖动，提示「最小化状态不能拖动面板，先点 ＋ 还原」。
- [ ] 6. 最小化状态点 **＋** 还原后，位置仍是折叠前的位置（折叠不改位置）；此后 Alt+F3 可以正常抓。
- [ ] 7. 拖动中用 ESC 取消：面板回到**抓起前**的位置（不是拖到一半的地方），并且这个"回原位"也会立刻写进 `ui.json`（重启后确认仍是原位）。
- [ ] 8. 拖动中把鼠标移出窗口让它自动放下：这次的位置**保留**（与 ESC 相反），重启后仍是这个位置。
- [ ] 9. 检查 `mpv-player\portable_config\source-markers-ui.json` 里能看到 `"panel_pos":[x,y]`（关掉 mpv 后用记事本打开看即可）。

# 术语标准：元素与操作

> **这份文件是干什么的**
> 同一样东西被叫成两个名字、或两个东西共用一个名字，是这一版里反复出问题的根源（「可视范围 / 可视区间 / 可见范围」混用、「出入点区间」把两个控件叫成一个、「区间」同时指三件事）。
> 从今往后**新增概念先在这里登记**，再拿去写正文/文档。

> **三条规矩**
> 1. **一物一名**：下表「正式名」是唯一写法，代码注释、文档、对话都只用它。
> 2. **要改名先改这张表**：别名只允许出现在「别再叫成」一栏，当反例用。
> 3. **拿不准先问**：宁可停下问一句，也别即兴造一个近义词。

## 一、时间轴（第 9 条）

### 1.1 界面元素

| 正式名 | 指什么 | 代码 | 别再叫成 |
|---|---|---|---|
| **可见范围** | 时间轴当前显示的那段时间窗 | `TL.t0` / `TL.t1`（秒）| 可视范围、可视区间、可见区间、显示范围 |
| **出入点** | 用户设的入点 / 出点 | `IN_FRAME` / `OUT_FRAME`（帧号，`source-markers.lua:833`）| 区间端点、范围端点 |
| **播放头** | 当前播放位置那根竖线 | `time-pos` | 光标、游标 |
| **时间轴** | 控制栏正上方那条带刻度、概览条的面板 | `UI.tl` / `o.tl` | 时间线、导轨 |
| **概览条** | 时间轴最底下那条 `⚪====⚪` | `tl_ov_*` | 进度条、滚动条、滑块条、bar |
| **亮段** | 概览条上两环之间的高亮部分 | — | 高亮、填充、选中段 |
| **环** / **圆环** | 亮段两端那两个空心圆，拖它改可见范围 | — | 圆点、滑块、把手、marker、标记 |
| **环心距** | 两环**圆心**之间的距离（**不是外沿距**）| `tl_ov_min_px` | 环距、外沿距、最小宽度 |
| **轨道** | 概览条里那条横向长条（环在上面走）| `rw` | 条、槽、track |
| **刻度带** | 时间轴中部的刻度尺 | — | 标尺、ruler |
| **中括号** | 出入点在时间轴上的 `[ ]` 标记 | `IN_FRAME` / `OUT_FRAME` | 出入点标记、方括号 |
| **标记头** | 时间轴上每个标记的三角头 | — | 旗标、旗子 |

### 1.2 操作与状态

| 正式名 | 指什么 | 代码 | 别再叫成 |
|---|---|---|---|
| **单动** | 拖环时只动被抓的那一端，另一端钉住 | `tl_grab_feel='mouse'` | 单端拖动、独立拖动 |
| **同动** | 两环**以播放头为轴对称**缩放 | `gr.sym` | 双动、联动、对称缩放 |
| **转嫁** | 单动的方向会让播放头远离中点时，改抓另一端 | `illegal` / `gr.trans` | 换手、翻转、镜像 |
| **钉住** | 决定「另一端」是按像素不动还是按时间不动 | `tl_ov_pin='px'\|'time'` | 锁定、固定 |
| **贴边** | 可见范围碰到片头 / 片尾 | `tl_ov_edge='pin'\|'pr'` | 到边、触界、撞墙 |
| **缩放锚点** | 滚轮缩放时播放头落在哪里 | `tl_zoom_anchor` | 锚点、基准点 |
| **最小跨度** | 时间轴最多能放大到多少帧 | `tl_min_frames`（默认 40 f）| 最小宽度、最小可视区间 |
| **播放跟随** | 播放/暂停时可见范围要不要跟着播放头走 | `tl_play_follow='pr'` | 自动跟随、滚动跟随 |

## 二、控制栏与面板（第 8 条）

| 正式名 | 指什么 | 代码 | 别再叫成 |
|---|---|---|---|
| **控制栏** | Pr 风格的传输控制条（播放/入出点/步进等按钮） | `UI.bar` / `prbar_metrics()` | 工具栏、按钮条、底栏 |
| **按钮面板** | 第 8 条之前的浮窗按钮集（F2 开关，可与控制栏共存但互斥显示） | `UI.panel` | 面板、浮窗、F2 面板 |
| **样式** | 二选一：`prbar`（控制栏）或 `panel`（按钮面板） | `UI.style` | 模式、外观 |

## 四、Pr 侧对照（写文档时按这张表换词）

| 我们这边 | Pr 那边 |
|---|---|
| 可见范围 | 时间轴下那条 `⚪====⚪` 滑块（Pr 帮助里也这么叫）|
| 时间轴 | 时间轴面板 |
| 控制栏 | 源监视器下方的传输控制栏 |
| 概览条 | 没有对应物（mpv 自创，Pr 的滑块只控制可见范围，不显示进出点）|
| 中括号 | Pr 的入点 / 出点标记 |
| 最小跨度 | Pr 的「最小可视范围」≈ 40~44 帧（与片长无关，实测）|

## 五、已废弃的说法（看到就改）

| 废弃 | 改成 | 原因 |
|---|---|---|
| 可视范围 / 可视区间 / 可见区间 | 可见范围 | 2026-10-28 全仓统一（91 处 / 16 个 .md）|
| 出入点区间 | 看语境：时间轴两端时间码说的是**可见范围**；中括号说的是**出入点** | 曾把两个独立实体叫成一个，导致「goto 不平移」被误判成「控件语义不同」|
| 区间（单独出现） | 写明是**可见范围**、**出入点**还是**拖动区间** | 「区间」在旧文档里同时指三件事 |

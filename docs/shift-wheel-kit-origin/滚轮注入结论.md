# 滚轮 & 按键滚轮注入结论

环境：Win11 + dsh-guikit 0.6.2；靶 Premiere Pro（hwnd 197154，注入点 694,694）

## 效果对比

| 注入路径 | 结果 |
|---|---|
| gui_scroll 单用（无修饰键） | ✅ 生效，1 格 = 1 条 WM_MOUSEWHEEL，delta=-120(down)/+120(up)，间隔 ~65ms |
| 外部 SendInput/keybd_event 按 Shift + 滚轮 | ❌ 无效（全局 GetAsyncKeyState 已 True，Premiere 不认） |
| gui_key 注入 F8 触发 AHK 热键 → 脚本 Send("{Shift down}") + 滚轮 | ✅ 有效，横向平移 |
| 人手按 F8（同上脚本） | ✅ 有效 |
| AHK 脚本顶层直接 Send("{Shift down}") | ❌ 无效 |

## 有效配方

1. 常驻：`C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe` 跑 `20261025_d9b99b.ahk`（`*F8` 切换 Shift 按住/松开）
2. `gui_key keys="F8"` → Shift 按住
3. `gui_window activate` 抢前置（最小化需先 SC_RESTORE）→ 逐格 `gui_scroll notches=1`，间隔 1s
4. `gui_key keys="F8"` → 松开
5. 校验 `GetAsyncKeyState(0x10)==0` 且 AHK 进程存活

## 坑

- 滚轮只投给**前台**窗口，与光标位置无关；目标未前置会误滚别的窗口
- notches 上限 20（传 50 也只发 20 条）；上一动作未停稳就滚会被吞（等 ≥1.5s）
- AHK ToolTip 自绘，GetWindowText 抓不到，不能当验证手段；判据只有全局键盘状态 + 画面
- 逐格注入起点间隔实测 ~1.85s（1s 等待 + ~0.85s 工具往返）
- Shift 卡住风险：脚本 OnExit 会释放，仍应复核键盘状态

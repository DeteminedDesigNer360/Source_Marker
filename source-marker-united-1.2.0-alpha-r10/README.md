# Source Marker 合并版 v1.2.0-alpha-r10「交织」(Weave)

把**两个相互配套的插件**放进同一个包，并让它们真正互通：

- **Pr 面板**（`pr-extension\`）—— 在 Premiere Pro 里查看 / 导入 / 导出 / 编辑 / 删除素材标记，编辑源片段入出点；
- **mpv 播放器**（`mpv-player\`）—— 自带 mpv 的绿色便携播放器，边看边打标记并导出标记文件。

两者**各自安装、各自独立使用**，只用其中一个也完全没问题。

> **开发代号**：本版为 **「交织」(Weave)** —— 两侧不再只是并排，而是**交织**在一起（共享颜色表、统一命名、键位向 Pr 看齐）。
> 上一版 1.1.0 的代号是 **「并轨」**：两条轨道合成一条 —— 那是"合起来"，这一版是"织起来"。
> 上一版（1.0.1-alpha）只把两侧收进同一个包、几乎没动代码；**1.1.0 起两侧开始真正互操作**。

## 包里有什么

```
source-marker-united-1.2.0-alpha-r10/
├── 快速上手.md              ← 先读这个（从打标记到导入 Pr 的完整流程）
├── README.md                本文件
├── 改动说明.md              所有改动、取舍与真机验证记录（想看"改了什么、为什么"就看它）
├── 安装.cmd                 ← 一键安装（Pr 面板 + 播放器「打开方式」+ 面板里的播放器路径）
├── 卸载.cmd                 一键卸载（面板目录会删；播放器是绿色便携，本体保留）
├── install-united.ps1       安装脚本本体（上面两个 .cmd 调它；支持 -DryRun 只预览不改动）
├── pr-extension/            Pr 面板（CEP 扩展）
│   ├── README.md            两个版本怎么选
│   ├── 新手版/              面向日常使用：双击 install.cmd
│   └── 完整版/              多出自检、导出策略选择、文件名模板 + 技术 README
└── mpv-player/              自带 mpv 的绿色便携播放器（免安装、解压即用）
```

- 两个 Pr 版本**扩展 ID 相同**（`com.frisk.sourcemarker`），**同一时间只能装一个**，互相覆盖。
- 播放器与 Pr 面板**互不依赖**：装不装 Pr 面板都不影响播放器，反之亦然。
- **「安装.cmd」做的事**：装 Pr 面板 + 把本包 mpv 注册进「打开方式」+ 把 mpv 路径写给面板
  （面板因此**第一次使用也不用再手动选播放器**）。它需要管理员权限（要写 Program Files），会弹 UAC。

## 三步跑通

1. **装**：双击包根的 **`安装.cmd`**（会问装哪个 Pr 版本；弹 UAC 时确认）
2. **用播放器打标记**：右键视频 → 打开方式 → mpv（或双击 `mpv-player\mpv.exe`）→
   按 `F2` 开按钮面板 → 打到满意后按 `Ctrl+e` 导出
3. **导入 Pr**：完全退出并重启 Premiere → 菜单 `窗口 > 扩展 > Source Marker` →
   源监视器里打开**同一个素材** → 面板「标记」栏点「**自动找标记**」（找不到就「选择文件…」）→ 点「导入」

**回程**（Pr → mpv/别人）：面板「标记」栏点「**导出到源目录**」，
会在素材同目录写出 `<素材名>_markers.csv` 与同名 `.json` —— **默认覆盖**，与播放器侧同规则。想留每一次的版本：面板勾上「导出时另存为迭代（带时间戳）」，播放器按 `Ctrl+Shift+E`。

> 标记是挂在**素材**上的，所以 Pr 里必须打开同一个素材才看得到。

细节见 `快速上手.md`。两边各自还有更细的说明：
`pr-extension\新手版\快速上手.md`、`pr-extension\完整版\README.md`、
`mpv-player\快速上手.md`、`mpv-player\README.md`。

## 环境要求

|            | 要求                                                                                   |
| ---------- | -------------------------------------------------------------------------------------- |
| Pr 面板    | Premiere Pro CC 2019（13.0）或更高；**Adobe Media Encoder**（导出功能依赖）；Windows   |
| mpv 播放器 | Windows x64；无需安装、不写注册表、不改系统设置（注册「打开方式」写的是 HKCU，用户级） |

Pr 面板的安装脚本是 PowerShell（系统级安装会自动请求提权）；macOS 需手动把
`pr-extension\…\extension\` 放进 CEP 扩展目录。播放器整个文件夹删掉即卸载。

## 完整性（**相对于三个原始发行版**）

本包的两个子包**起点**是各自的独立发行版：

| 子包                  | 起点                       |
| --------------------- | -------------------------- |
| `pr-extension\新手版` | `source-marker-1.0.0`      |
| `pr-extension\完整版` | `source-marker-1.0.0-full` |
| `mpv-player`          | `mpv-source-markers-1.0.0` |

**1.1.0 起，两侧都做了功能改动**：相对三个原始发行版共 **16 个文件**有差异，
每一个都在 **`改动说明.md`** 里有据可查（改了什么、为什么、真机验证结论）。
三个原始发行目录在开发仓库里**原封不动保留**，作为可回滚的基线。

可自行核对：

- `mpv-player\校验.ps1` —— 对播放器逐个文件核对哈希（16 个文件）；
- `pr-extension\…\install.ps1` —— 装完会逐文件 MD5 比对，确认装的就是包里的这一份；
- `安装.cmd` 的 `-DryRun` —— 只打印将要做什么，不改文件、不改注册表、也不提权。

## 已知的说明

- 子包内部的说明文字仍按**上游开发仓库**的目录书写（例如 `player-plugin/`、
  `docs/marker-format.md`、`backup/`）。那些路径是发行版原样带入的**上游引用**，
  不是本包内的路径；在本包里请按上面「包里有什么」的目录结构找文件。
- 标记交换格式已冻结为 v1，规范写在 `mpv-player\标记文件格式-v1.md`。
- **已知限制**（都是实测确认的能力边界，不是没做）：
  - Pr 的「活动监视器」无法由面板切换 —— 点面板标记不会让源监视器变成活动监视器，
    因此按空格仍按 Pr 自己的规矩（播哪个监视器由你在 Pr 里最后点的那个决定）。
    面板提供了「播放源 / 暂停源」按钮作为替代。
  - CEP 面板内的**中文输入法候选窗位置**不可靠（面板全境皆然，属 CEP/CEF 通病）；
    因此改标记正文走的是 **Pr 原生输入框**，在那里输入法正常。

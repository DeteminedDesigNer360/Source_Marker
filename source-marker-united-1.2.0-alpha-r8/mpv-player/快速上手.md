# Source Markers 播放器 · 快速上手

这是一个**自带 mpv 的绿色便携播放器**：解压就能用，不用安装、不写注册表、不改系统设置。
它能在你看片的时候于播放头处打标记（时间戳 + 颜色 + 描述），导出成 Premiere 的
**Source Marker** 面板能直接导入的标记文件。

---

## 30 秒上手

1. **解压**到任意目录（桌面、文档、D 盘都行；**不要**放进 `C:\Program Files`，那里可能没有写权限）；
2. 把视频文件**拖到 `mpv.exe` 上**（或者拖到 `打开视频.cmd` 上）；
3. 按 **`F2`** 打开按钮面板 —— 所有功能都能用鼠标点；不熟悉的话先按 **`F1`** 看快捷键；
4. 打到满意的标记后按 **`Ctrl+e`** 导出，屏幕左上角会显示导出路径；
5. 打开 Premiere → `窗口 > 扩展 > Source Marker` → 源监视器里打开同一个素材 →
   选「标记文件」挑刚导出的 `.csv` → 点「导入标记」。

> 标记是挂在「素材」上的，所以 Pr 里要打开**同一个素材**才能看到它们。

## 快捷键（按 `F1` 也会显示这一份）

| 键 | 作用 |
|---|---|
| `F1` | 帮助浮窗（快捷键一览 + 颜色图例） |
| `F2` | **按钮面板**（鼠标点一切；位置会记住） |
| `Ctrl+m` | 在播放头打标记（用当前颜色） |
| `Alt+m` | 打标记并写描述 —— **描述就是 Pr 里看到的标记名** |
| `Ctrl+1` … `Ctrl+8` | 选颜色（对应 Pr 标记色 0 绿 / 1 红 / 2 紫 / 3 橙 / 4 黄 / 5 白 / 6 蓝 / 7 青） |
| `Ctrl+l` | 显示 / 隐藏标记列表 |
| `Alt+n` / `Alt+p` | 跳到下一个 / 上一个标记（帧精确） |
| `Alt+g` | 按序号跳转 |
| `Alt+e` | 编辑最近标记的描述 |
| `Ctrl+DEL` | 删除最近的标记 |
| `Ctrl+e` | 导出 CSV/JSON（默认路径直接回车） |
| `Ctrl+i` | 导入标记文件（CSV / TSV / JSON / SRT） |

播放器常用键：`空格` 暂停 / `←` `→` 前后 5 秒 / `Shift+←` `Shift+→` 精确 1 秒 /
`↑` `↓` 前后 1 分钟 / `f` 全屏 / `q` 退出。

## 常见问题

**导出的文件在哪？**
屏幕左上角会显示完整路径。默认与视频放在同一目录，文件名形如
`你的视频名_markers.csv`（同时会写一份同名 `.json`，信息更全）。

**视频旁边那个 `.marks.json` 是什么？**
自动保存的标记文件——关掉播放器再打开同一个视频，标记会自动回来。
它**默认是隐藏文件**（资源管理器里看不见），这是为了防止误删误改。

**描述和名字是怎么回事？**
Premiere 那边把「描述」当作标记的显示名。所以本播放器**只让你填描述**，
标记文件里那一列「名字」保留着但**始终是空的** —— Pr 也整列忽略它。
这是刻意设计的，避免"明明填了名字，Pr 里显示的还是描述"这种困惑。

**想把标记带到 Pr，但 Pr 里没有 Source Marker 面板？**
先安装面板：见本包 `pr-extension\新手版\`（双击里面的 `install.cmd`）。

**卸载 / 不要了？**
整个文件夹删掉就完事。它不会往系统里写东西（除了你打开视频时旁边生成标记文件）。

**播放不流畅 / 黑屏？**
在 `portable_config\mpv.conf` 里加一行 `hwdec=auto` 试试；老显卡可以改成 `hwdec=no`。

**想改键位、改面板位置？**
见 `README.md` 的「可调项」一节，或按 `F1` 里的提示。

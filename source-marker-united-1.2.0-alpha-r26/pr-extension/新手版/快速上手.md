# Source Marker 快速上手

给 Premiere Pro 装的一个小面板，让你在**源监视器**里划好入点出点之后直接导出这一段，
也能把播放器/其它工具生成的标记文件一次性导入成 Pr 的标记。

不需要懂编程，装一次、点几下就能用。

---

## 一、装一次就好

1. 双击仓库根目录的 **`install.cmd`**
2. 弹出「是否允许更改」就点 **是**（要写入 Program Files，需要管理员权限）
3. **完全退出** Premiere Pro（任务管理器里确认没有 `Adobe Premiere Pro.exe` 残留），再重新打开
4. 顶部菜单 **`窗口 > 扩展 > Source Marker`**

装完后如果菜单里没有这个面板，先确认 Pr 是真的全部退出了。

---

## 二、三个主要用法

### 用法 1：把源监视器里划好的一段导出去

1. 在**源监视器**里打开素材，用 Pr 自带的 `I` / `O` 键划出入点和出点
2. 面板第一栏会实时显示这个片段的名称、入点、出点
3. **第一次使用**要填两个位置，各点一次「选择…」：
   - **保存到** → 选一个文件夹
   - **输出格式** → 选一个 Media Encoder 预设（`.epr` 文件）
   
   这两个**只需选一次，以后会自动记住**，重开 Pr 也还在。
4. 看一眼「文件名」那一行（就是最终会生成的文件名），点 **「导出这一段」**

导出会交给 Adobe Media Encoder 处理。勾选了「导出后自动开始渲染」的话，
AME 会自己开始跑，你不需要切过去手动点「开始队列」。渲染期间别关 AME。

### 用法 2：把这一段放到时间线

1. 先在时间线面板把播放头放到想插入的位置
2. 面板上选「插入」或「覆盖」
3. 填轨道号：**V1 就是第一条视频轨**，A1 就是第一条音频轨
4. 点 **「放到时间线」**

### 用法 3：导入标记文件

1. 点 **「选择文件…」** 选一个标记文件（CSV / JSON / SRT / TSV 都行）
2. 想覆盖掉这个素材上原有的标记，就勾上「导入前先清空已有标记」
3. 点 **「导入」**
4. 下方列表会出现所有标记，**点任意一条就能把源监视器的播放头跳过去**

标记的名称取自文件里的「内容/备注」列。标记文件里的 `name` 列**整列忽略** ——
播放器早先会在那一列写 `M01`、`M02` 这类占位编号，现在已不再生成。

---

## 三、入点 / 出点 那一栏还能做什么

| 按钮 | 作用 |
|---|---|
| 入 / 出 输入框 + 「应用」 | 直接键入精确时间码（格式 `00:00:10:00`） |
| 跳到入点 / 跳到出点 | 把源监视器播放头跳到对应位置 |
| 微调 + 入− 入＋ 出− 出＋ | 按帧微调入点或出点 |
| 读取时间线的入出点 | 把时间线当前入出点复制到源监视器 |
| 写到时间线 | 反过来，把源监视器的入出点写到时间线 |
| 清除 | 清掉源监视器的入出点 |

## 四、常见问题

**导出到哪了？**
「保存到」那一栏就是文件夹，「文件名」那一栏就是完整文件名。

**手上没有 `.epr` 预设文件？**
打开 Adobe Media Encoder → 菜单「预设」→「导出预设」，随便存一个到好找的位置。

**导出后工程里多了一个叫 `SM 00.00.10.00-…` 的序列？**
那是导出用的临时序列，必须存在到 AME 渲染结束。渲染完成后点面板右下角的
**「清理导出产生的临时序列」** 即可一次清掉。不用了就点一下，不影响别的序列。

**点了「导出这一段」没反应？**
看底部「状态」那块的文字，它会说明卡在哪一步（例如预设文件找不到、输出文件夹不可写）。

**想反馈问题？**
点「复制状态信息」，把复制到的内容发出来即可。

**想恢复成开发者版本？**
本仓库的 `backup/source-marker-full-20261006/` 里保留了完整版（含自检、导出策略选择、
文件名模板等），双击那个目录里的 `install.cmd` 就能装回去。

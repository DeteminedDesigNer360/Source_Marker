## 11. 以下**不是**缺陷，是已确认的能力边界

- **活动监视器无法由面板切换**：只要「源」不是在 Pr 的蓝色选框下，按空格播的总是序列。
  替代方案：面板的「播放源 / 暂停源」按钮。
- **CEP 面板内的中文输入法候选窗位置不可靠**（面板全境皆然）→ 改标记正文走 Pr 原生输入框。
- **「跳到 In/Out」与微调跟随走 QE 通道**（官方 API 无此能力）→ 极端情况下可能有个别失败，日志会写明原因。
